Quiet Tasks previously stored refresh tokens as JSON and replicated task data across fallback directories. This PR keeps native SwiftUI/WidgetKit, moves tokens into app-only Keychain storage, uses one App Group with checked legacy migration, and hardens OAuth/HTTP handling. Sandbox, hardened runtime, and the no-token-JSON/no-public-folder-write protections remain enabled.

The current goal is personal Mac testing with a free Apple Account. Defaults are `com.personal.quiettasks`, `com.personal.quiettasks.widget`, and `group.com.personal.quiettasks`; Team ID stays unset and all identifiers remain configurable. No paid signing credentials are required for the CI build or ad-hoc attempt. The optional Developer ID/notarization job is separate future work.

Validation: 32 tests passed, including synthetic real-Keychain storage and mocked Google sync/error handling. The macOS build and static ad-hoc app/extension signature, sandbox, hardened-runtime and App Group declaration checks passed. On macOS 15.7.9 arm64, the app container writer exited 0 and PluginKit registered/listed the extension candidate. **Shared widget reads remain unverified:** direct extension execution aborted with `An XPC Service cannot be run directly` (SIGABRT/-6). Gatekeeper rejected the ad-hoc app (exit 3). Registry success and embedded entitlements do not prove WidgetKit execution or capability authorization.

Download **Quiet-Tasks-ADHOC-PERSONAL-TEST** and **Quiet-Tasks-ADHOC-DIAGNOSTICS** from Actions → macOS test build → the exact commit run → Artifacts. [Installation/testing instructions](https://github.com/sicfloyd/quiet-tasks/blob/security/harden-google-tasks/Docs/PERSONAL_TESTING.md) use built-in macOS tools, explain per-app review only when macOS offers it, and require stopping on unsupported behavior. No local Xcode is needed for those steps. [Validation evidence](https://github.com/sicfloyd/quiet-tasks/blob/security/harden-google-tasks/Docs/VALIDATION.md) and [threat model/findings](https://github.com/sicfloyd/quiet-tasks/blob/security/harden-google-tasks/SECURITY_REVIEW.md) distinguish observed results from potential risks.

Personal Mac launch, desktop WidgetKit behavior, shared reads, actual-app Keychain authorization, and real-account OAuth are not tested. Apple-issued signing/notarization are not performed. No Google account was connected, protection disabled, binary deployed, or public release published. Keep this PR in draft for review and actual personal-Mac testing.
